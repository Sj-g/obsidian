产品将以438c方式进行编写，为了方便后续将以markdown的方式进行编写

| 阶段   | 文档            | 作用                   |
| ---- | ------------- | -------------------- |
| 计划阶段 | 软件开发计划        | 说明怎么开发、谁负责、里程碑、交付物   |
| 需求阶段 | 软件需求规格说明      | 说明软件必须实现什么功能和性能      |
| 设计阶段 | 软件概要设计说明      | 说明软件整体架构、模块划分、数据流    |
| 设计阶段 | 软件详细设计说明      | 说明每个模块内部逻辑、接口、数据结构   |
| 测试阶段 | 软件测试计划 / 测试说明 | 说明如何测试、测什么、测试环境      |
| 测试阶段 | 软件测试报告        | 说明测试结果、缺陷、是否通过       |
| 交付阶段 | 软件用户手册        | 说明用户如何使用软件           |
| 交付阶段 | 软件安装部署说明      | 说明如何安装、配置、运行         |
| 管理阶段 | 软件配置管理计划      | 管理版本、代码、文档、基线        |
| 管理阶段 | 需求跟踪矩阵        | 建立需求、设计、代码、测试之间的追踪关系 |
