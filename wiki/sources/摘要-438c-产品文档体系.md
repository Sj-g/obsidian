## 核心摘要
本资料梳理了基于 [[GJB438C]]（军用软件开发文档通用要求）的项目文档体系。它按软件生命周期阶段（计划、需求、设计、测试、交付、管理）将文档分类，给出每类文档的作用与英文常见简称，并区分"必写"与"视情况"的文档。资料还提供了一个标准化的 438C 项目文档包目录结构组织方案（按 01_计划类 / 02_需求类 / 03_设计类 / 04_测试类 / 05_交付类 / 06_验收类 分文件夹管理）。

## 关键信息
**核心实现文档（按阶段）：**

| 阶段 | 代表文档 | 作用 |
|------|----------|------|
| 计划阶段 | 软件开发计划 | 怎么开发、谁负责、里程碑、交付物 |
| 需求阶段 | 软件需求规格说明 (SRS) | 软件必须实现什么功能和性能 |
| 设计阶段 | 概要/详细设计说明 | 整体架构、模块划分、内部逻辑、接口 |
| 测试阶段 | 测试计划/说明/报告 | 如何测试、测什么、测试结果与缺陷 |
| 交付阶段 | 用户手册/安装部署说明 | 用户如何使用、如何安装配置 |
| 管理阶段 | 配置管理记录/需求跟踪矩阵 | 版本基线管理、需求到代码的追踪 |

**完整文档清单（16类，含必写项）：**软件开发计划、软件需求规格说明、接口需求规格说明、软件概要设计说明、软件详细设计说明、接口设计说明、数据库设计说明、软件测试计划/说明、软件测试用例、软件测试报告、软件问题报告、软件用户手册、软件操作手册、软件安装部署说明、软件版本说明、软件配置管理记录。

**文档包组织结构：**
```
XX软件项目_438C文档包/
├── 01_计划类文档/
├── 02_需求类文档/   (含需求跟踪矩阵)
├── 03_设计类文档/
├── 04_测试类文档/
├── 05_交付类文档/
└── 06_验收类文档/
```
