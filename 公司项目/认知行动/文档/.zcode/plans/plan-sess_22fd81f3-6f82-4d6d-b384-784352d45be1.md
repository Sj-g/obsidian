# 四元绑定逻辑修改 — 全量修改计划

## 新逻辑定义（已确认）

| 绑定关系 | 旧 → 新 |
|---|---|
| agent_id ↔ account_id | 1:1 → **1:N**（一个智能体绑多个账号） |
| account_id ↔ 记忆 | 隐含在 agent → **显式 1:1**（每账号独立记忆，按 account_id 索引） |
| account_id ↔ 动态提示词 | 隐含在 agent → **显式 1:1**（每账号独立动态提示词） |
| account_id ↔ 终端 | 1:1（不变） |
| 终端 ↔ 代理IP | 1:1（不变） |
| **II-14 同步主键** | agent_id → **agent_id + account_id 组合**（SWM 为每个组合生成独立动态提示词包同步给 MC） |
| **资产迁移** | agent 整体继承 → **账号→账号迁移**（被封账号的记忆+动态提示词迁移到新账号；agent 不变仍绑新账号） |

**核心语义转变**：提示词/记忆的归属从 agent_id 维度 → account_id 维度。提示词模板仍按 agent_id（智能体共性），动态提示词实例+记忆按 account_id（账号个性）。
