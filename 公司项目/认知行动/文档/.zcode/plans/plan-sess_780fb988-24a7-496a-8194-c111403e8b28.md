# drawio 架构图生成方案

## 范围（用户已确认）
- **7 个子系统**各一张图：DC / MC / OM / COM / SWM / OCC / IRS
- **每个 .drawio 一张图**（7 个独立文件）
- 存放：**新建 `文档/架构图/` 子目录**，文件名 `架构图-XX子系统.drawio`
- **混合详略度**：主区画模块关系（M-XX-NN 节点 + 内部箭头），外围标注部署单元/技术栈/数据库/外部产品/邻接子系统

## 信息源（不依赖 SDD）
- **结构骨架**：`软件概要设计说明.md` §4.x 各子系统 intro 的 mermaid（最新 V3.0，含 M-MC-15）
- **节点属性补充**：`SRS/软件需求规格说明-XX子系统.md` + `SRS/软件需求规格说明-总册.md` §6.7 运行环境 + §6.9 CON-01~15
- **V1.0 范围**：`MVP功能清单.xlsx` 总览页

## 每张图的内容（按子系统列要点）

### 1. DC 数据爬取子系统
- 模块：M-DC-01 调度限流 / M-DC-02 多平台采集与策略自优化 / M-DC-03 数据处理与存储(ETL) / M-DC-04 情报驱动采集与目标扩散

### 2. MC 多设备矩阵自动化群控子系统（最复杂，4 部署单元）

## 实施步骤
1. **创建目录** `文档/架构图/`
2. **手写 7 个 `.drawio` 文件**（drawio 原生 mxGraph XML 格式，UTF-8）：
   - 每个文件结构：`<mxfile><diagram><mxGraphModel><root><mxCell id="0"/><mxCell id="1" parent="0"/><!-- 节点+边 --></root></mxGraphModel></diagram></mxfile>`
   - 节点用 `<mxCell vertex="1"><mxGeometry x= y= width= height= as="geometry"/></mxCell>`
   - 边用 `<mxCell edge="1" source= target=>...<mxGeometry relative="1" as="geometry"/></mxCell>`
3. **每个文件画布尺寸**：1400×900 起步，MC 因为节点多放到 1600×1100
4. **每个文件标题区**：左上角文本块"XX 子系统架构图 · V3.0 / V3.10 · 2026-07-21 · 对应 SRS XX 分册 + HLD §4.x"
5. **图例区**（右下角）：颜色含义对照表
6. **一致性自检**：grep 各 .drawio 里的 M-XX-NN / II-NN / EI-NN 编号与 HLD/SRS 对照，无遗漏无错编
7. **更新 `文档目录.md`** 加 `架构图/` 一行说明
8. **追加版本变动记录**：V3.10 一条「新增 7 张子系统 drawio 架构图」

## 不做的事
- 不做 HLD §3.1 总图（用户选了只做 7 张子图）
- 不做时序图/状态机/类图（用户要的是架构图）
- 不修改 HLD/SRS 任何正文（drawio 是补充产物，源文档不动）
- 不引入 drawio CLI 或转换工具（直接手写 XML，样式精确可控）
