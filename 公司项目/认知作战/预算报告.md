# 马来西亚社媒数据采集预算报告

## 1. 概述

本报告用于估算马来西亚地区社媒平台用户表采集项目的内部技术直接成本。

当前估算按以下目标展开：

- 覆盖平台：Facebook、Instagram、TikTok、X
- 采集对象：马来西亚地区平台用户表
- 采集周期：2 个月完成一轮完整用户表爬取
- 保存内容：解析后的结构化文本、评论、用户信息，写入 HBase
- 不保存内容：HTML 原文、图片、视频

本报告只估算技术直接成本，包括代理流量、云服务器、账号损耗和存储设施；不包含研发人员、运营人员、合规审查、税费、利润和对外报价加成。

> 说明：平台广告覆盖人数不是严格意义上的月活人数，也不是唯一自然人数量。但在没有平台真实用户库的情况下，它是估算“用户表规模”的可用公开口径。四个平台用户会重叠，因此本报告按“平台用户表分别爬取”计算，不做跨平台去重。

## 4. 统一计算公式

### 4.1 日爬取量

```text
日均爬取量 = 平台用户表规模 / 60 天
```

### 4.2 代理费用

```text
单条代理计费流量 = 5KB × 1.2 = 6KB
单条代理成本 = 6KB / 1,000,000 × 61.2 元/GB = 0.0003672 元/条
单轮代理费用 = 平台用户表规模 × 0.0003672 元
年度代理费用 = 单轮代理费用 × 6
```

### 4.3 HBase 存储容量

```text
单轮结构化数据量 = 平台用户表规模 × 单条结构化记录大小
年度结构化数据量 = 单轮结构化数据量 × 6
HBase 工程容量 = 年度结构化数据量 × HDFS 副本系数 × HBase/索引/预留系数
```

> 代理费用按请求下载流量计算，包含 20% 重试和失败请求缓冲；HBase 存储只按解析后的结构化结果计算，不保存 HTML 原文。

- 主要风险是登录态稳定性、频控、账号异常验证和公开可见性不足。
