# 马来西亚社媒数据采集预算报告

## 1. 概述

本报告用于估算马来西亚地区社媒平台用户表采集项目的内部技术直接成本。

当前估算按以下目标展开：

- 覆盖平台：Facebook、Instagram、TikTok、X
- 采集对象：马来西亚地区平台用户表
- 采集周期：2 个月完成一轮完整用户表爬取
- 年度周期：一年 6 轮全量刷新
- 保存内容：用户 HTML 原文、文本、评论、用户信息
- 不保存内容：图片、视频

本报告只估算技术直接成本，包括代理流量、云服务器、账号损耗和存储设施；不包含研发人员、运营人员、合规审查、税费、利润和对外报价加成。

> 说明：平台广告覆盖人数不是严格意义上的月活人数，也不是唯一自然人数量。但在没有平台真实用户库的情况下，它是估算“用户表规模”的可用公开口径。四个平台用户会重叠，因此本报告按“平台用户表分别爬取”计算，不做跨平台去重。

## 4. 统一计算公式

### 4.1 日爬取量

```text
日均爬取量 = 平台用户表规模 / 60 天
```

### 4.2 代理费用

```text
单条代理计费流量 = 1.5MB × 1.2 = 1.8MB
单条代理成本 = 1.8MB / 1000 × 61.2 元/GB = 0.11016 元/条
单轮代理费用 = 平台用户表规模 × 0.11016 元
年度代理费用 = 单轮代理费用 × 6
```

### 4.3 HTML 存储容量

```text
单轮 HTML 原文容量 = 平台用户表规模 × 1.5MB
年度 HTML 原文容量 = 单轮 HTML 原文容量 × 6
工程容量 = HTML 原文容量 × 副本系数
```

> 代理费用按请求下载流量计算，包含 20% 重试和失败请求缓冲；HTML 存储按最终保存的原文计算，不叠加 20% 代理缓冲。

**平台差异**

- Facebook 用户规模大，但私密内容和权限限制较多。

- 如果扩展到好友关系、群成员、评论互动关系，采集条数会明显高于 2,300 万用户表规模。
- 主要风险是登录态稳定性、频控、账号异常验证和公开可见性不足。

## 8. 账号及反爬对抗损耗费用

账号成本不能直接固定，需要按平台账号池规模和损耗率计算。

```text
初始账号池费用 = 初始账号数量 × 人民币账号单价
月账号补充费用 = 初始账号数量 × 月损耗率 × 人民币账号单价
年账号补充费用 = 月账号补充费用 × 12
```

| 平台 | 反爬强度 | 建议单独确认项 |
| --- | --- | --- |
| Facebook | 中 | 账号池规模、登录态保持、公共内容覆盖率 |
| Instagram | 高 | 账号池规模、挑战验证比例、公开账号覆盖率 |
| TikTok | 极高 | 账号池规模、设备指纹、验证码和封禁率 |
| X | 高 | 账号池规模、登录墙、请求限制和 API 策略 |
