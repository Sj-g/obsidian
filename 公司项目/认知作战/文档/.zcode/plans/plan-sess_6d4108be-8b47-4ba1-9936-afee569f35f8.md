# 系统页面清单 + coze-loop 架构变更全量修订

## 已确认的共识（grill 结论）

| 决策点 | 结论 |
|---|---|
| 页面边界 | **仅 Web 管控控制台**（排除移动端 Agent、桌面端指纹浏览器 Profile、IRS GPU 运维） |
| 门户拓扑 | **多子系统独立控制台 + SSO**（非统一单平台） |
| 控制台范围 | **4 个控制台**：OCC 作战中心 / MC 设备矩阵控制台 / SWM 智能体工厂 / OM&COM 运维管理。**DC 与 IRS 不设 Web 页面**（DC 纯后端/API 驱动；IRS 走 OM 可观测） |
| 颗粒度 | **一级菜单 + 二级页面（路由级）**，每页一句话职责 + 主要角色 + 对应模块 M-XX-NN |
| coze-loop | **魔改内核 + 自研统一 UI**（不再是旁挂黑盒）；**全量修订** SRS/HLD/SWM SDD |
| 横切页 | 单列「通用页面」一节（SSO 登录、控制台门户、个人中心、错误页、通知中心） |

## 角色映射权威源（来自 COM SDD §4.2 已验证）

6 角色：超级管理员/运营主管/运营人员/脚本开发者/审核人员/只读观察员。子系统×动作（view/operate/manage）权限矩阵已验证。页面清单每页据此标注主要角色（标最高权限的非超管角色 + 超管兜底）。

### C. MC 设备矩阵控制台（6 一级菜单 → 19 二级页）

6. **执行审计**：执行网关熔断监控页 / 动作审计与作业统计复盘页（M-MC-10，9 功能点）/ 智能体宿主同步状态页（M-MC-14）
