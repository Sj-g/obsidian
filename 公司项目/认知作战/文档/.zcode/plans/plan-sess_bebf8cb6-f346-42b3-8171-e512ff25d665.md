# 新建《软件详细设计说明-SWM子系统.md》V1.0

## 定位
补上 V3.7 联动遗漏的 SWM 详细设计文档。严格套用 COM/DC/OM 三份 SDD 的 10 章固定框架，采用**集成层写法**（coze-loop 黑盒 + Java 自研全粒度）。

## 写作原则（3 条红线）
1. **SWM 不含运行时**：不写场景适配/动态调用/调 IRS 视觉推理/读记忆注入运行时——这些都是 MC agent-runtime 职责（CON-10/11）。SWM 只写到「生成提示词包 + 承载记忆 + 同步 MC + 评测」为止。
2. **coze-loop 黑盒**：M-SWM-02/06/07 只写 Java 适配层类 + 调 coze-loop 的 OpenAPI 契约 + 配置项，不写 coze-loop 内部实现。
3. **M-SWM-03 编号缺口**：§1.2 加 `> 说明：` 澄清 M-SWM-03 已移 MC agent-runtime、编号废止、M-SWM-04+ 保留原编号。

### 第 5 章 模块详细设计（核心，6 节）

- **5.3 M-SWM-04 蜂群记忆管理（R-SWM-002）**【Java swm-memory，全粒度】：classDiagram（MemoryStore/分层记忆）+ 记忆存储/沉淀/复用算法 + **边界声明：记忆由 MC agent-runtime 远程读取，验收入口在 §5.5 loop 评估器**。
- **5.4 M-SWM-05 智能体构建与提示词包下发（R-SWM-003）**【Java swm-gw/distill，全粒度】：classDiagram + 提示词包组装算法（agent_id 不重分配仅升版本，P5）+ II-14 同步时序图（含重试幂等，≥99%）。
- **5.5 M-SWM-06 智能体评测与迭代决策（R-SWM-004）**【coze-loop evaluation 承载，黑盒】：Java 适配层 + OpenAPI 契约（评测集/评估器/实验）+ **实验运行状态机**（运行中/完成/失败/部分失败，唯一状态机）+ 迭代淘汰决策算法（及格60/淘汰40）+ **R-SWM-002 记忆有效性验收入口在此**（loop 评估器可用线）。
- **5.6 M-SWM-07 按账号与画像自动生成提示词（R-SWM-005）**【coze-loop 工作流承载，黑盒】：Java 适配层 + 自动生成时序图（拉 MC II-01 → 拉 OCC II-18 → 调 IRS EI-05 → 版本化回写）+ 异常分支（账号缺失/画像缺失降级/IRS 失败重试/质量不达标人工微调）。
