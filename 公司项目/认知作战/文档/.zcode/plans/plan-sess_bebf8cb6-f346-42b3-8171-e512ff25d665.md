# SWM 子系统结构性大改 — 落地计划

## 背景
基于 grill 出的 8 项转向决策（P1–P8）+ 刚确认的 4 项细化，一次性全改 7 个文件，全部升版。

## 本次定稿的最终决策集
- **P1** 删 studio，loop 为核心；agent=生成的提示词包
- **P2** 保留 swm-memory + runtime 归 MC
- **P3** swm-memory 改 Java；loop 成唯一外部 Go 服务
- **P4** MC 内拆 agent-runtime 子模块，保 CON-10 语义
- **P5** agent_id=稳定逻辑ID+版本子属性
- **P6** 用户画像从 OCC 拉（R-OCC-004 全维度档案），新增 II-18
- **P7** 删 A/B 双跑，用 loop 静态评测集
- **P8** R-SWM-002 验收基线交给 loop evaluator 配置
- **细化1** M-SWM-03 整体移 MC + 删 II-09（SWM 模块 6→5）
- **细化2** 新增 R-SWM-005（按账号+画像自动生成提示词）
- **版本** SRS V3.6→V3.7，HLD V2.5→V2.6，架构图 V1.3→V1.4，模块拆分/RTM 跟随
